# Content Integrity

Allowed: restructure verified facts, shorten copy, ask for missing context, or insert `[verify this claim]`.

Forbidden: invent employers, customers, revenue, percentages, user counts, performance improvements, dates, degrees, certifications, awards, quotes, or ownership.

For each strong claim, request one of: repository evidence, demo evidence, artifact, public link, measurement method, or a clear first-person explanation the candidate can defend in an interview.
