# Recruiter Rubric

Score 0–2 for each dimension: 0 missing, 1 present but weak, 2 clear and credible.

| Dimension | Evidence sought |
|---|---|
| Positioning | Target role and level are obvious |
| Credibility | Claims are specific and defensible |
| Projects | Problem, ownership, technology, decisions, outcome |
| Technical depth | Tradeoffs and constraints, not only tool names |
| Communication | Scannable language and useful headings |
| Contact | One safe, working primary path |

Do not treat visual polish as proof of technical ability.
