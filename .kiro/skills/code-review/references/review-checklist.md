# Review Checklist

- Approved requirement is actually satisfied.
- Semantics and heading order match the information structure.
- Links and buttons use the correct element and behavior.
- Keyboard and focus behavior are preserved.
- Responsive rules do not depend on one device width.
- User-controlled content is handled safely.
- No duplicate component, magic constant, dead code, or avoidable dependency.
- No accidental manifest, lockfile, deployment, or unrelated change.
- Validation covers the changed behavior.
