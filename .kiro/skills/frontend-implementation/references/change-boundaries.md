# Change Boundaries

Allowed only when mapped to an approved task: components, styles, local assets, semantic markup, verified copy, metadata, and existing tests.

Require separate approval: manifest or lockfile changes, new packages, framework migration, analytics, forms that send data, external scripts, deployment files, generated content presented as fact, or broad refactoring.

A change is small enough when it can be reviewed from one focused diff and reverted without disturbing unrelated sections.
