# Frontend Implementation

1. Confirm the approved task, mapped requirements, allowed files, and expected evidence.
2. Read nearby patterns before editing.
3. Use Context7 only for an API or framework behavior that needs current documentation.
4. Apply `references/change-boundaries.md`.
5. Make the smallest coherent change.
6. Inspect `git diff` for accidental scope.
7. Run `node .kiro/skills/frontend-implementation/scripts/validate-project.mjs`.
8. Complete `templates/change-report.md` and stop.

Never install packages or convert an unknown candidate fact into copy.
