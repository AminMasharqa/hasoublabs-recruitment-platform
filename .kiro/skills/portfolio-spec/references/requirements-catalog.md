# Requirement Examples

- `WHEN a first-time visitor loads the home page, THE SYSTEM SHALL identify the candidate and target role in the first viewport.`
- `WHEN a project is displayed, THE SYSTEM SHALL present the problem, candidate contribution, technology, and verified outcome.`
- `WHEN the viewport is 390 pixels wide, THE SYSTEM SHALL present all primary content without horizontal scrolling.`
- `WHEN a keyboard user presses Tab, THE SYSTEM SHALL expose a visible focus indicator on every interactive element.`
- `WHEN an external link opens a new tab, THE SYSTEM SHALL use safe rel behavior.`

Avoid vague criteria such as “modern,” “beautiful,” or “professional” unless translated into observable rules.
