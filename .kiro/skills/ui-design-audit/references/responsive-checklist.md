# Responsive Checklist

- No horizontal scrolling at 390px.
- Navigation remains reachable by keyboard and touch.
- Hero copy does not create orphaned single words.
- Primary action stays visible and large enough to activate.
- Project cards preserve title, role, problem, contribution, and outcome order.
- Images keep aspect ratio and useful focal points.
- Content does not rely on hover alone.
- Focus styles are visible against every background.
- Motion respects `prefers-reduced-motion`.
