# Portfolio Visual Hierarchy

The first viewport should answer: who, target role, strongest value, and next action.

Use one dominant heading, one short supporting statement, and one primary action. Establish consistent heading levels, readable line lengths, deliberate whitespace, and repeated project-card anatomy. Avoid equal visual weight for every section, decorative motion without purpose, low-contrast muted text, and skill-logo walls with no evidence.

Suggested token minimum: 1 background, 1 surface, 1 body text, 1 muted text, 1 accent, 1 danger/focus color; 3–5 type sizes; one spacing scale; one radius family.
