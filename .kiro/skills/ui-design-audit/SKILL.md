# UI Design Audit

1. Capture the first impression at desktop and mobile viewports.
2. Apply `references/visual-hierarchy.md` and `references/responsive-checklist.md`.
3. Run `node .kiro/skills/ui-design-audit/scripts/check-css-tokens.mjs` to identify accidental color and type sprawl.
4. Distinguish usability defects from stylistic preferences.
5. Propose a compact token set and component rules, reusing the current design where possible.
6. Complete `templates/ui-audit.md` without editing code.

Prioritize identity, target role, evidence, projects, and contact action. Decoration is secondary.
