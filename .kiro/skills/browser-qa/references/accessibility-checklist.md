# Browser Accessibility Checks

- Page has one clear primary heading and logical heading order.
- Every interactive element is reachable by keyboard.
- Focus is visible and not obscured.
- Links have meaningful names and correct destinations.
- Images have useful alternative text or are correctly decorative.
- Content does not depend only on color, hover, or motion.
- Form controls have labels and useful error behavior.
- Reduced-motion mode remains usable.

Browser inspection supports, but does not replace, testing with disabled users and assistive technology.
