# Evidence Report

Every completion claim needs observable proof. Use only `Pass`, `Fail`, or `Blocked`. Separate pre-existing problems from change-introduced problems. Map evidence to requirement and task IDs, and assign every unresolved item to an owner.

Use `templates/final-evidence.md`. Include commands, URLs, viewports, files, screenshots, or reports that produced each result. End with known gaps and the next human decision.
