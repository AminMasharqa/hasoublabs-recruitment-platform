# GitHub Publication Checklist

## Privacy and repository hygiene

- `.env`, keys, credentials, private endpoints, and local personal data are excluded.
- `node_modules`, `dist`, `build`, coverage, editor state, and OS files are ignored.
- No résumé file exposes a home address, private phone number, identity number, or hidden metadata.
- Generated screenshots contain no unrelated tabs, accounts, notifications, or tokens.
- Repository history does not contain an earlier secret.

## Professional quality

- Repository name is readable and relevant.
- Description explains the portfolio and primary technology.
- README includes purpose, screenshot, stack, local setup, validation, decisions, and candidate ownership.
- License is chosen intentionally; do not add one automatically.
- Project links work and unsupported claims are absent.

## GitHub mutations requiring approval

- Create or change repository visibility.
- Commit or push files.
- Create issues, branches, pull requests, releases, or tags.
- Modify the profile README repository.
- Enable GitHub Pages, Actions, Dependabot, or security settings.
